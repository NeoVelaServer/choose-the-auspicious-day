# choose-the-auspicious-day

通过通胜黄历分析日子吉凶与宜忌，依据**建除十二神**、**值神**、**星宿**等要素给出详细择日建议。

---

## 功能概述

本 Skill 用于 Trae AI 开发环境，当用户询问择日、选日子、看黄历、判断某日吉凶宜忌、是否适合嫁娶/搬家/开业/出行等事务时自动触发。

核心能力：
- 调用 **通胜黄历 MCP** 获取每日黄历数据
- 基于 **建除十二神** 判断日子基调
- 基于 **十二值神（黄道/黑道）** 判断日子吉凶
- 基于 **二十八星宿** 分析星象影响
- 分析 **宜忌事项**、**冲煞方位**、**时辰吉凶**
- 输出综合评级与择日建议

## 安装使用

### 1. 安装到 Trae 项目

将本仓库克隆到你的项目目录：

```bash
git clone https://github.com/NeoVelaServer/vanguard-vela-choose-the-auspicious-day.git
cd vanguard-vela-choose-the-auspicious-day
```

然后将 `.trae/skills/choose-the-auspicious-day/` 目录复制到你的项目 `.trae/skills/` 目录下即可。

### 2. 前置依赖

本 Skill 依赖 **通胜黄历 MCP**（`mcp_Tong_Sheng_MCP`），请确保你的环境中已配置该 MCP 服务。

MCP 工具信息：
- **Server**: `mcp_Tong_Sheng_MCP`
- **Tool**: `get-tung-shing`
- **功能**: 获取公历、农历、宜忌、吉凶、冲煞、时辰等信息

## 分析维度

### 建除十二神

建除十二神依次为：**建、除、满、平、定、执、破、危、成、收、开、闭**，决定当日整体基调。

| 建除神 | 吉凶 | 主要含义 |
|--------|------|---------|
| 建 | 吉 | 万物开端，宜建立、出行，忌动土 |
| 除 | 吉 | 除旧布新，宜沐浴、清洁、治病 |
| 满 | 平 | 圆满丰收，宜开市、交易 |
| 平 | 平 | 平顺安稳，宜修饰垣墙 |
| 定 | 吉 | 稳定确定，宜嫁娶、安床 |
| 执 | 小凶 | 执行把握，宜捕捉，忌交易 |
| 破 | 凶 | 破败损耗，宜破土、拆卸 |
| 危 | 凶 | 危险不安，宜安床，忌出行 |
| 成 | 吉 | 成功成就，宜开市、嫁娶 |
| 收 | 小凶 | 收获收敛，宜纳财，忌安葬 |
| 开 | 吉 | 开启开通，宜开业、出行 |
| 闭 | 小吉 | 关闭封锁，宜安葬，忌嫁娶 |

### 十二值神（黄道/黑道）

**六黄道（吉）**：青龙、明堂、金匮、天德、玉堂、司命  
**六黑道（凶）**：天刑、朱雀、白虎、天牢、玄武、勾陈

### 二十八星宿

二十八星宿分属四象（东方青龙、北方玄武、西方白虎、南方朱雀），每宿有独立吉凶属性。

### 时辰吉凶

将一日分为十二时辰（子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥），每个时辰有独立的值神与吉凶判断。
