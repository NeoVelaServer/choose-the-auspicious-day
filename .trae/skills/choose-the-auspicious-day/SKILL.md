# 择日通胜分析

当用户询问某日吉凶、宜做何事、是否适合某项活动时，按以下步骤执行。

## 1. 确定目标日期

- 若用户明确指定日期，使用该日期（转换为 YYYY-MM-DD 格式）。
- 若用户说"今天"、"明天"、"后天"等，从系统上下文中获取当前日期并推算。
- 若用户未指定日期，默认查询今天。
- 若用户想比较多个日期，可连续查询并对比分析。

## 2. 调用通胜 MCP 获取黄历数据

使用 `run_mcp` 调用 `mcp_Tong_Sheng_MCP` 的 `get-tung-shing` 工具：

```json
{
  "server_name": "mcp_Tong_Sheng_MCP",
  "tool_name": "get-tung-shing",
  "args": {
    "startDate": "YYYY-MM-DD",
    "days": 1,
    "includeHours": true
  }
}
```

参数说明：
- `startDate`：目标日期，格式为 "YYYY-MM-DD"
- `days`：查询天数，默认 1 天
- `includeHours`：是否包含时辰信息，建议设为 true

## 3. 详细分析维度

获取到黄历数据后，从以下维度进行详细分析并输出：

### 3.1 基本信息
- 公历日期、星期
- 农历日期（年月日）
- 干支纪年、纪月、纪日
- 节气（如当日恰逢节气需特别标注）

### 3.2 建除十二神分析
建除十二神依次为：建、除、满、平、定、执、破、危、成、收、开、闭。

| 建除神 | 吉凶属性 | 主要含义 |
|--------|----------|----------|
| 建 | 吉（忌动土） | 万物开端，宜建立、出行，忌动土、开仓 |
| 除 | 吉 | 除旧布新，宜沐浴、清洁、治病、除服，忌嫁娶、出行 |
| 满 | 平 | 圆满丰收，宜开市、立券、交易，忌动土、栽种 |
| 平 | 平 | 平顺安稳，宜修饰垣墙、平治道涂，忌掘井、伐木 |
| 定 | 吉 | 稳定确定，宜冠笄、安床、嫁娶、纳采，忌词讼、出行 |
| 执 | 吉（小凶） | 执行把握，宜捕捉、畋猎，忌开市、交易、嫁娶 |
| 破 | 凶 | 破败损耗，宜破土、拆卸、治病，忌嫁娶、立券、开市 |
| 危 | 凶（小心） | 危险不安，宜安床、捕捉，忌出行、起造、安葬 |
| 成 | 吉 | 成功成就，宜开市、嫁娶、入学、出行，忌词讼 |
| 收 | 吉（小凶） | 收获收敛，宜纳财、开市、捕捉，忌安葬、出行 |
| 开 | 吉 | 开启开通，宜开业、嫁娶、出行、求嗣，忌安葬 |
| 闭 | 凶（小吉） | 关闭封锁，宜安葬、补垣，忌开市、出行、嫁娶 |

**分析要点**：说明当日建除神为何，结合其所主之事判断整体基调。

### 3.3 值神分析
十二值神（青龙、明堂、天刑、朱雀、金匮、天德、白虎、玉堂、天牢、玄武、司命、勾陈）轮流值日，分黄道吉日与黑道凶日。

**六黄道（吉）**：青龙、明堂、金匮、天德、玉堂、司命  
**六黑道（凶）**：天刑、朱雀、白虎、天牢、玄武、勾陈

**分析要点**：明确当日值神属于黄道还是黑道，说明其吉凶属性及对当日气场的影响。

### 3.4 二十八星宿分析
二十八星宿分为四象（东方青龙、北方玄武、西方白虎、南方朱雀），每宿有独立吉凶。

**主要吉凶宿参考**：
- 吉宿：角、房、尾、箕、斗、牛、女、虚、危、室、壁、奎、娄、胃、昴、毕、觜、参、井、鬼、柳、星、张、翼、轸（具体需结合实际）
- 凶宿：心、亢、氐、房等（部分宿在不同事上有不同宜忌）

**分析要点**：指出当日值日星宿，说明其五行属性与吉凶倾向。

### 3.5 宜忌分析
- **宜**：当日适合进行的事项，需逐条列出并说明对用户询问事项的匹配度。
- **忌**：当日应避免的事项，需逐条列出并说明对用户询问事项的影响。
- 若当日"诸事不宜"或"馀事勿取"，需特别警示。

### 3.6 冲煞分析
- **冲**：当日地支冲克的生肖，提醒相关生肖之人谨慎。
- **煞**：当日不利方位（如煞东、煞西），提醒避免向该方位行事。
- **胎神**：当日胎神所占方位，孕妇相关事务需注意。

### 3.7 时辰吉凶（如 includeHours 为 true）
若返回了时辰信息，列出各时辰（子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥）的吉凶：
- 说明哪些时辰为吉时，哪些为凶时。
- 若用户有具体事项，推荐最佳时辰。

## 4. 综合判定与输出格式

最后给出综合结论，按以下结构输出：

```
【日期】YYYY年MM月DD日（农历...）
【干支】...
【建除十二神】... — ...（吉凶判断与解释）
【值神】... — ...（黄道/黑道说明）
【星宿】...宿 — ...（吉凶说明）
【冲煞】冲... 煞...（生肖与方位提醒）
【宜】...（逐条说明）
【忌】...（逐条说明）
【时辰吉凶】...（如有时辰信息）

━━━━━━━━━━━━━━━━━━
【综合评级】大吉 / 吉 / 平 / 凶 / 大凶
【适合】...（总结最适合做的事）
【不宜】...（总结最应避免的事）
【特别提示】...（针对用户问题的专门建议）
```

**评级规则**：
- 建除吉 + 黄道值神 + 吉宿 + 宜多忌少 = 大吉/吉
- 建除平 + 黄道/黑道参半 = 平
- 建除凶 + 黑道值神 + 凶宿 + 忌多 = 凶/大凶

**注意事项**：
- 若用户询问具体事项（如"今天适合搬家吗"），需结合宜忌直接回答，引用黄历数据作为依据。
- 若多个日期对比，需用表格或分块对比呈现。
- 分析必须基于通胜 MCP 返回的真实数据，不得编造。
- 如果 MCP 调用失败，向用户说明并建议稍后重试。
